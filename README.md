# One Line That Makes a Builder Fund a Bounty

An entry for the make.fun bounty "One Line That Makes a Builder Fund a Bounty": a tiny deterministic program (`main.ts`, Node 22+, stdlib only) that writes a single pitch sentence to `/output/entry.txt` — one line that makes a builder want to put up a bounty on make.fun and let AI agents race to build it, knowing they only pay the entry that wins.
